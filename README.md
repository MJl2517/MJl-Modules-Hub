# MJl - Modules Hub

Каталог модулей MJl для Foundry VTT 14.361 и новее в линейке v14. Hub можно включить отдельно. Сами модули работают без Hub, а доступные связи между ними указаны в карточках.

## Установка

В меню настройки Foundry откройте **Модули → Установить модуль** и вставьте адрес манифеста.

```text
https://raw.githubusercontent.com/MJl2517/MJl-Modules-Hub/main/module.json
```

Запустите мир, включите **MJl - Modules Hub** через управление модулями и сохраните настройки. Мастер может открыть витрину с левой панели или через меню настроек.

Foundry устанавливает пакеты в меню настройки сервера. Кнопка **Установить** показывает адрес GitHub и предлагает выйти в меню настройки. Вставьте адрес в штатный установщик, запустите мир снова и нажмите **Включить в мире**. Управление модулями покажет стандартное окно перезагрузки после сохранения. Для установки с паролем сервера нужен доступ администратора Foundry.

## Каталог и уведомления

Карточка показывает обложку, название и категорию. Выберите модуль, чтобы открыть описание, версии, требования к Foundry и действия в правой панели. Если версия сервера вне заданных границ или манифест не подтверждён, установка и обновление из Hub недоступны. Отметка «не проверено» означает, что текущая версия Foundry новее проверенной автором либо проверенная версия не указана.

Добавляйте карточки в `catalog.json` в ветке `main`. Для витрины нужен публичный манифест `module.json` с ZIP-пакетом из того же репозитория MJl2517. Записи без манифеста пропускаются. Отдельный репозиторий на каждый модуль не обязателен, если для каждого манифеста и архива предусмотрены свои публичные адреса.

Hub проверяет каталог при входе мастера и каждые 30 минут открытой сессии. Мастер получает личное сообщение в чате с номерами новых версий модулей, включённых в мире, включая сам Hub. Кнопка **Открыть обновления** в сообщении открывает каталог с фильтром **Есть обновление**. Сообщения о той же версии в этом браузере не повторяются. Автоматическую проверку можно отключить в настройках мира. Кнопка **Проверить версии** обновляет данные в каталоге вручную. При недоступном GitHub отображается каталог из установленного пакета.
